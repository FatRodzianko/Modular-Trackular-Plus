# Polyend Tracker CE - Config Menu Descriptions
# Format: [key] followed by multi-line description text.
# Lines starting with '#' are comments.

[pattDiv]
Highlights each chosen step, to give you better visual feedback in the pattern. 

[radioReg]
Adjusts radio frequencies to the chosen region.

[displBright]
Sets display brightness. 

[displTheme]
Selects the color scheme of the user interface.

[displFont]
Selects the font of the user interface.

[padsBright]
Sets the brightness of the pad lights in the grid.

[recNotes]
Sets what information is stored when recording: quantized notes only, notes with microtiming, quantized notes with velocity, or notes with microtiming and velocity. You need to record with an external MIDI device to record velocity. 

[recThreshold]
Defines in microtiming units, how soon notes should be captured by live recording. This is useful when you play too early during a preroll.

[perfPres]
You can store your Perform presets globally (the same settings for all projects) or locally (each project has its own presets).

[scale.mini]
The selected scale applies to the Note popup display and the notes generated by the Random Note FX. All scales are based on equal temperament tuning.

[scale]
All scales use equal temperament tuning. Use the chromatic scale if you want the pad board to use all twelve semitones. This gives you four full octaves with the base note in the first column of each line. 

[rootNote]
Defines the note at the bottom-left of the Note popup.

[padLay]
For the first (leftmost) column in the Note popup, this value sets how many semitones higher should each note in the row above be compared to the row below. For example, a value of 3 will make the note above the Root the 4th note of the scale (1 + 3), the note two rows above the Root the 7th note (1 + 3 + 3), and so on. Use this setting to customise your Note popup for more convenient note selection. 

[antial]
Disabling anti-aliasing gives the vintage feeling. The samples are harsher when detuned heavily. 

[limiter]
Determines how attack and release of the limiter are treated. Subtle limiting gives a more transparent sound but will not be able to catch very sudden changes in amplitude. Extreme limiting reacts much faster which colors the sound. 

[sends]
Pre-fader sends are independent of the instrument volume. This allows the wet signal to be louder than the dry signal. Post-fader sends are proportional to the instrument volume. This gives a more consistent sound when volume is modulated. 

[headroom]
Enables more headroom in the audio signal path by reducing the input gain of sample playback at the source to avoid clipping and improve overall dynamic range.

[snapToZero]
When setting Start/End markers in Sample Playback editor, sudden sample amplitude changes can cause pops and clicks. To avoid this, activate this mode to automatically snap the markers when they are set close to the zero amplitude points which are indicated with the green marker color.

[maxTracks]
Limits the number of active visible and audible tracks (4, 8, 12, or 16) for a focused or retro workflow. All 16 tracks remain preserved internally in the project.

[hexMode]
Enable the throwback hex goodness: pattern step numbers start with 00 and use sixteen digits (A means 10, B means 11, and so on all the way to F which means 15). This allows for easy alignment with music: your music bars will always start with pattern steps 00, 10, 20, 30, ... Each bar's quarternote beat steps end with the digits ..0, ..4, ..8, and ..C. 

[patternArra]
Pattern arrangement type

[patternInfo]
Pattern info

[noteDisplayMode]
Choose how notes are displayed in Pattern View: Original (C4, C#4) or Traditional (C-4, C#4).

[usbAudio]
Enables audio over USB. For best results connect the device directly to your computer USB port (USB hubs are not supported) before launching your DAW and set it up as an aggregate audio device. Find more details in our user manual at polyend.com

[padsPrev]
On the Pattern editor screen, the grid pads can highlight the note in the active line. Choose between highlighting only the active track's notes, or the entire pattern's active line.

[slaveClockComp]
Allows compensating latency of incoming clock signal by number of clock pulses, where 1 pulse = 1/6 of step. Use this with "Clock in" set to MIDI IN jack or USB.
