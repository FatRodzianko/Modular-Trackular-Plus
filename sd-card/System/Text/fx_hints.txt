# Polyend Tracker CE - Step FX Help Descriptions
# Format: [KEY] for shared/Original descriptions, [KEY.SYNTH] for Synth-enabled variants.
# Lines starting with '#' are comments.

[NONE]
Destination: Sample, MIDI 

Indicates that there's no effect used on the desired step.

[NONE.SYNTH]
Destination: Sample, Synth, MIDI 

Indicates that there's no effect used on the desired step.

[OFF]
Destination: Sample, MIDI 

Toggle off the effect used on previous step.

[OFF.SYNTH]
Destination: Sample, Synth, MIDI 

Toggle off the effect used on previous step.

[VOLUME]
Destination: Sample, MIDI 

Sets the Volume of an Instrument. For MIDI instruments this sends the NOTE ON Velocity parameter. 

From 0% to 100%.

[VOLUME.SYNTH]
Destination: Sample, Synth, MIDI 

Sets the Volume of an Instrument. For MIDI instruments this sends the NOTE ON Velocity parameter. For Synth instruments sets the Macro 7. 

From 0% to 100%.

[PANNING]
Destination: Sample 

Sets the Panning of an Instrument.

From -50 (L) to +50 (R).

[PANNING.SYNTH]
Destination: Sample, Synth 

Sets the Panning of an Instrument or Synth.

From -50 (L) to +50 (R).

[MICROTUNING]
Destination: Sample, MIDI 

Sets the microtuning adjustments.

From -99 cents to +99 cents.

For MIDI instruments sends pitchbend message.

[MICROTUNING.SYNTH]
Destination: Sample, Synth, MIDI 

Sets the microtuning adjustments. For MIDI instruments and Synths this sends the pitchbend message.

From -99 cents to +99 cents.

[GLIDE]
Destination: Sample 

Sets the time it takes for the pitch of previous note to travel to the pitch of corresponding note.

From 0-49% (0-1s) 
to 50-100% (1-15s).

[TEMPO]
Destination: Pattern

Changes pattern tempo. Handy to create custom swings or grooves.

From 10 BPM to 400 BPM.
Also includes TSTP value which stops the playback. TSTP value is excluded when Tempo FX is used in combination with Random FX Value (f).

[SWING]
Destination: Pattern

Changes pattern swing.

From 25% to 75%.

[MICROMOVE]
Destination: Sample, MIDI 

Slightly moves (nudges) forward the step position.

From 0% to 100%.

[MICROMOVE.SYNTH]
Destination: Sample, Synth, MIDI 

Slightly moves (nudges) forward the step position.

From 0% to 100%.

[GATE_LENGTH]
Destination: Sample, MIDI 

Sets length of note if you need shorter than step

From 0% to 100%.

[GATE_LENGTH.SYNTH]
Destination: Sample, Synth, MIDI 

Sets length of note if you need shorter than step

From 0% to 100%.

[CHANCE]
Destination: Sample, MIDI 

Sets a chance or condition for a step being played.

0-100: Probability %
GL / !L: Group / Not Last
1:1-6:6: Play N / Skip M
S11-S66: Skip N / Play M

[CHANCE.SYNTH]
Destination: Sample, Synth, MIDI 

Sets a chance or condition for a step being played.

0-100: Probability %
GL / !L: Group / Not Last
1:1-6:6: Play N / Skip M
S11-S66: Skip N / Play M

[ROLL]
Destination: Sample, MIDI 

Sets the type and value of the Roll (step divider) parameter.

From 0 to 16 for each Roll type.
R - regular Roll.
Rv - decreasing volume Roll.
RV - increasing volume Roll.
Rn - decreasing note Roll.
RN - increasing note Roll.
RR - random note Roll.

[ROLL.SYNTH]
Destination: Sample, Synth, MIDI 

Sets the type and value of the Roll (step divider) parameter.

From 0 to 16 for each Roll type.
R - regular Roll.
Rv - decreasing volume Roll.
RV - increasing volume Roll.
Rn - decreasing note Roll.
RN - increasing note Roll.
RR - random note Roll.

[ARP]
Destination:  MIDI 

Combine with the Chord effect (0xx) to arpeggiate in the given tempo divider, either in raising /, falling \, or random R pitches.

[ARP.SYNTH]
Destination: Synth, MIDI 

Combine with the Chord effect (0xx) to arpeggiate in the given tempo divider, either in raising /, falling \, or random R pitches.

[RANDOM_NOTE]
Destination: Sample, MIDI 

Sets the range of randomization for Note with each sequencer pass.

From +/- 0 to +/- 100

[RANDOM_NOTE.SYNTH]

[RANDOM_INSTRUMENT]
Destination: Sample, MIDI

From +/- 0 to +/- 47

[RANDOM_INSTRUMENT.SYNTH]
Destination: Sample, Synth, MIDI

From +/- 0 to +/- 47

[RANDOM_VALUE]
Destination: Sample, MIDI 

Sets the range of randomization for the FX that is in the same step with each sequencer pass. For example, if randomizer value is 10 and affected FX value is 100, the algorithm will pick the value from 90 to 110.

From +/- 0 to +/-255.

[RANDOM_VALUE.SYNTH]
Destination: Sample, Synth, MIDI 

Sets the range of randomization for the FX that is in the same step with each sequencer pass. For example, if randomizer value is 10 and affected FX value is 100, the algorithm will pick the value from 90 to 110.

From +/- 0 to +/-255.

[RANDOM_VOLUME]
Destination: Sample, MIDI

From +/- 0 to +/- 100

[RANDOM_VOLUME.SYNTH]
Destination: Sample, Synth, MIDI 

Sets the range of randomization for Volume (Sample), Velocity (MIDI) or Macro 7 (Synth) with each sequencer pass.

From +/- 0 to +/- 100

[AMP_ENV]
Destination: Sample 

Sets Volume Envelope Attack and Decay/Release times simultaneously.

Value is represented as two hexadecimal digits (AR):
First digit (A): Attack time (0: 0ms stab .. F: 8s rise).
Second digit (R): Decay/Release time (0: 0ms .. F: 8s).
In Wavetable mode, modulates speed and time warp.

[FILTER_ENV]
Destination: Sample 

Sets Filter Envelope Attack and Decay/Release times simultaneously.

Value is represented as two hexadecimal digits (AR):
First digit (A): Attack time (0: 0ms stab .. F: 8s rise).
Second digit (R): Decay/Release time (0: 0ms .. F: 8s).
In Wavetable mode, modulates filter speed and time warp.

[GRANULAR_LENGTH]
Destination: Sample 

Sets the Grain Length for an Instrument in Granular Playback mode.

0-50% maps 1ms to 100ms, 50-100% maps 100ms to 1000ms (clamped to sample length).

From 0% to 100%.

[MIDI_CHORD]
Destination: MIDI 

Sends many MIDI notes or sets up Arp.
Numbers represent semitones above the base note. For example, C-4 047 will play a major chord: C-4 (base note), E-4 (base+4), and G-4 (base+7).
Try:
027: Sus2   057: Sus4
037: Min    047: Maj
05C: Open4  07C: Open5
0379: Min6  037A: Min7
0479: Maj6  047A: Maj7
047B: MajMaj7
After 057B, inversions:
038: Maj/1st  059: Maj/2nd
049: Min/1st  058: Min/2nd

[MIDI_CHORD.SYNTH]
Destination: MIDI, Synth

047B: MajMaj7
